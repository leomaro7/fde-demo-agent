# 打ち合わせメモ（サンプル）

**これは架空の打ち合わせメモである。** 実在の企業・人物とは関係がない。

`new-demo` スキルと `RUNBOOK.md` 3.1 を試すための素材として置いてある。
**わざと「答えてはいけないこと」を書いていない。** 本物の打ち合わせメモには
絶対に書かれないためである（要件書 3.4）。ここが埋まっているメモを使うと、
このスキルが何のためにあるのかを検証したことにならない。

## このメモの使い方

```
このメモで案件を起こしたい（内容は docs/sample-meeting-note.md）
```

と伝えると `new-demo` が起動する。**スキルは必ず 2 項目を聞いてくる。**

1. **このデモで答えてはいけないことは何か**
2. クライアント名

**1 はこのメモに書かれていない。** 意図的にそうしてある。
本物の打ち合わせでもクライアントは「できるようになりたいこと」しか話さない。
**聞き出せなければ、何でも答えるデモができて運用部門に刺さらない**（要件書 3.4）。

答えを考える材料は、メモの中に散らばっている。

- 部長が挙げた「一番怖い」こと
- 情シス主任が触れた確認が要るもの
- 具体例のうち 1 つは**このデモでは扱えない**もの
- 設備が止まっている場面で、AI が判断してよいことと、人が決めるべきこと
